# סטודיו התמונות של רבקה — Cloudflare

גרסה עצמאית של הסטודיו: ממשק React בעברית ושרת Cloudflare Worker הפונה ל־OpenAI API.
אחרי הפריסה פותחים את כתובת האתר באנדרואיד, בטאבלט או במחשב. אין צורך במחשב Windows דלוק. יצירת תמונות דורשת אינטרנט.

## מה כלול

- עשרה סגנונות ועשרים פלטות צבעים מהמסמך של רבקה; יצירת סצנה חדשה סביב המוצר ללא מסגרת.
- שליטה במראה: לשוניות "סגנון" ו"פרטים" (משטח, תאורה, רקע, בקשה מיוחדת עד 200 תווים), לשונית "צבעים" עם המועדפות של רבקה (מונוכרום ומדבר) למעלה, ואייקון לכל פלטה. הסגנון קובע ברירות מחדל למשטח, תאורה ורקע, ובחירה מפורשת גוברת עליהן; "חזרה לברירות הסגנון" מאפסת. "בוטיק" ו"ספא" בלי אבן ובלי שיש.
- רשימת "אף פעם לא" (ברירת מחדל: שיש ועומס) שאפשר לערוך, נכנסת לכל פרומפט כ־`Strictly avoid`, ומסונכרנת. פריט שהשם שלו ברשימה (למשל משטח "שיש") חסום בבחירה ולא נכנס לפרומפט.
- מתכונים בסרגל שבכותרת: ארבעה מובנים (בוטיק שחור-לבן, בוטיק מדבר, מינימליסטי שחור-לבן, מינימליסטי מדבר), שמירה של המראה הנוכחי, הפעלה ומחיקה. "מינימליסטי שחור-לבן" הוא ברירת המחדל בפתיחה. מתכון שומר מראה בלבד (בלי מוצר ובלי בקשה מיוחדת) והוא מסונכרן בין המכשירים.
- אביזרים: "ללא אביזרים" (ברירת מחדל) ו"אביזר אחד עדין". "עשיר" מוסתר ב"הגדרות מתקדמות" בלשונית "סגנון".
- היסטוריה של עד 30 תמונות. כל תמונה נשמרת עם ההגדרות שיצרו אותה, הפורמט ודירוג (טובה / לא טובה), ולחיצה עליה מחזירה את כל ההגדרות למסך. "הכל" פותח את כל ההיסטוריה.
- הנחיות לפי סוג מוצר: שמונה סוגים (נר בכלי זכוכית, נר בקרמיקה, נר עמוד או מפוסל, נמסים ריחניים, סבון חתוך, סבון בתבנית, פצצת אמבט, מארז מתנה). לכל סוג מקטע הנחיה משלו בפרומפט: זכוכית (שבירה והשתקפויות אמיתיות, בלי ברק שמכסה את התווית), קרמיקה (מרקם מט), עמוד או מפוסל (שמירה על הצורה המפוסלת), סבון חתוך (מרקם החיתוך, בלי מראה פלסטיקי) ופצצת אמבט (מרקם אבקתי). אין כלי בטון לנרות.
- מצב הנר (כבוי, דולק או כמו בצילום), גוון הזכוכית (שקופה, חלבית או ענברית) ועטיפת המארז (כמו שהוא או עטוף) מופיעים בממשק ובפרומפט רק לסוג המוצר שאליו הם שייכים.
- זווית צילום (גובה עיניים, 45°, מלמעלה, תקריב; בלחיצה שנייה חוזרים ל"כמו בצילום") ואירוע (חנוכה, ראש השנה, ט"ו בשבט, יום המשפחה, חתונה, ולנטיין). האירוע משפיע רק על פרטי הסצנה ולעולם לא על המוצר; בלי אביזרים הוא מתבטא באווירה וצבע בלבד.
- **התאמה למסך:** התמונה מוצגת תמיד בשלמותה בתוך אזור התצוגה (בכל מצב תצוגה ובכל פורמט, גם סטורי לאורך). "100%" מציג אותה בגודל מלא עם גלילה, ובכל טעינה חוזרים להתאמה למסך.
- **צבעי הממשק:** כפתור הצבעים בכותרת מחליף את צבעי הממשק לאחת מ־20 הפלטות. ברירת המחדל היא הירוק והזהב של רבקה. הצבעים נגזרים משלושת צבעי הפלטה ונבדקים בבדיקות לקריאות לכל הפלטות, והבחירה מסונכרנת בין מכשירים.
- כותרת עם הלוגו והסלוגן של רבקה במרכז, המתכונים מימין והסנכרון וההגדרות משמאל. כפתורים ואייקונים בתחושת תלת־ממד.
- **סרטון פתיחה** (`public/assets/rebecca-intro.mp4`, ועותק WebM לדפדפנים שלא תומכים) מוצג בכל פתיחה של האפליקציה. הוא מתחיל בלי קול (דפדפנים לא מאפשרים אחרת), עם כפתורים להפעלת קול ולדילוג (גם Esc), ונסגר בסיומו. מי שהגדיר בדפדפן "הפחתת תנועה" לא רואה אותו. כדי להחליף אותו מחליפים את הקבצים בתיקייה.
- ממשק לפי המוקאפ המאושר (`docs/ui-mockup/`): פס לשוניות עם אייקונים (סגנון, צבעים, מוצר, מיתוג, פורמט), אריחים עם אייקון נושאי, תמונה גדולה במרכז ושלושה מצבי תצוגה: "זה לצד זה", "תמונה אחת" ו"לפני ואחרי" (סליידר). במסך 1280×800 ובטאבלט לרוחב כל האפשרויות נגישות בלי גלילה; בטלפון לשונית פעילה אחת. בלשונית "מיתוג" פקדי המיקום הקיימים עדיין ארוכים וייתכן שם גלילה, עד עורך המיתוג של שלב 2.
- **עורך מיתוג** (מסך מלא, נפתח מלשונית "מיתוג" או מכפתור "עריכת מיתוג"), עם שלוש שכבות: לוגו, סלוגן וטקסט.
  - **הזזה וגודל:** גרירה, ידיות שינוי גודל (Transformer של react-konva) ושמירה על פרופורציות. אפשר לבטל את השמירה ולשנות גובה בנפרד.
  - **דיוק:** מקשי החיצים מזיזים פיקסל אחד (Shift: עשרה, ביחידות של פיקסל בפורמט), כפתורי הזזה למגע, ושדות מספריים באחוזים בדיוק של עשירית.
  - **יישור והצמדה:** קווי עזר חכמים שנצמדים למרכז, לשוליים (5%), לקצוות, לאזור המוצר ולקצוות ולמרכז של שכבה אחרת (Alt מבטל הצמדה). שש פעולות יישור ושני פיזורים שווים. היישור "ביחס ל": כל התמונה, שכבה אחרת או אזור המוצר.
  - **אזור המוצר:** קו מקווקו סביב 60% המרכזיים. הוא מופיע בעורך בלבד ולא בקובץ שנשמר.
  - **קריאות על הרקע:** צל עדין או מסגרת, גרסה כהה או בהירה ללוגו ולסלוגן, ושקיפות.
  - **טקסט:** גופנים Heebo, Assistant, Rubik ו־Frank Ruhl Libre (נארזים עם האתר ונטענים עם `FontFace` לפני הציור), מודגש, וצבע מתוך הפלטה הפעילה.
  - **פריסה לכל פורמט** נשמרת בנפרד ומסונכרנת בין המכשירים; "החלה על כל הפורמטים" מעתיקה אותה לכולם, ו"איפוס פריסה" מחזיר פורמט אחד לברירת המחדל.
  - **חיתוך ידני:** גרירת התמונה בתוך מסגרת הפורמט.
  - **מה שרואים הוא מה שנשמר:** העורך והקובץ שנשמר מציירים את אותה סצנה (`src/brand/BrandScene.tsx`), בקואורדינטות של הפורמט.
- בחירת פורמט פרסום ל־Instagram, Facebook, WhatsApp, TikTok, Pinterest, LinkedIn, YouTube ו־X. קובץ PNG מיוצא במידות הנבחרות; המעבר ליחס רוחב וגובה אחר חותך את התמונה מהמרכז, ויש לבדוק שהתוצר כולו נשאר גלוי.
- תצוגה מותאמת למסך, הורדת PNG עם המיתוג, ושמירת 30 התוצאות האחרונות.
- כל קובצי התמונות המקוריים בתיקיית public/assets. מסך הפתיחה אינו מציג דוגמאות מוצר.
- כניסה בסיסמה להגנת הממשק ופעולת היצירה.

## פריסה דרך Cloudflare Workers

1. העלו את תוכן הפרויקט למאגר GitHub.
2. ב־Cloudflare, בחרו Workers & Pages ויצירת Worker מתוך מאגר Git, וחברו את המאגר. ודאו שהחשבון המקושר מעניק ליישום Cloudflare Workers and Pages גישה למאגר.
3. תיקיית הבסיס היא שורש המאגר. פקודת בנייה: `npm run build`; פקודת פריסה: `npx wrangler deploy`. השתמשו ב־Node 22.13 ומעלה.
4. בהגדרות Variables and Secrets של ה־Worker הגדירו כסודות מוצפנים:
   - `OPENAI_API_KEY` — המפתח האישי של חשבון OpenAI API.
   - `STUDIO_PASSWORD` — סיסמה ארוכה וייחודית לסטודיו.
5. שם המשתמש הוא `rebecca`; ניתן לשנות את `STUDIO_USER` בקובץ wrangler.jsonc.
6. פתחו את כתובת workers.dev, הזדהו ובדקו יצירת תמונה והורדתה.

אין לשמור מפתח API בקוד, במאגר או במשתני VITE. לא הועתקו סודות מהאתר הישן. בהיעדר סיסמה השרת לא מאפשר גישה.

## פריסה משורת פקודה

```sh
npm ci
npx wrangler login
npx wrangler secret put OPENAI_API_KEY
npx wrangler secret put STUDIO_PASSWORD
npm run deploy
```

## פיתוח ובדיקות

```sh
npm ci
cp .dev.vars.example .dev.vars
# מלאו את הסודות בקובץ המקומי בלבד
npm run preview
npm test
```

`npm run preview` מפעיל גם את השרת המקומי. `npm run dev` מפעיל ממשק בלבד.

## נתונים ומעבר מהאתר הישן

הלוגו, הסלוגן, מיקומם וגודלם (וכן רשימת "אף פעם לא" והמתכונים) מסתנכרנים בין המכשירים דרך Cloudflare KV, בנתיב `/api/settings` שמאחורי אותה כניסה בסיסמה. הגבלה: עד 1MB להגדרות, ועד כ־700KB לכל קובץ לוגו או סלוגן שהועלה; קובץ גדול מזה נשמר במכשיר הזה בלבד וההודעה בממשק אומרת זאת. השרת מאמת כל שדה, ומסרב לקובץ שאינו תמונה (או SVG עם תוכן פעיל). אם KV לא מחובר, הממשק ממשיך לעבוד עם שמירה מקומית ומציג "לא מסונכרן". 30 התמונות האחרונות נשארות בדפדפן ובמכשיר שבו נוצרו, ללא סנכרון. הכתובת החדשה אינה מקבלת אוטומטית את הנתונים מהכתובת הישנה: שמרו משם תמונות רצויות והעלו מחדש את הלוגו והסלוגן. אין עדיין כלי ייצוא/ייבוא של כל ההיסטוריה.

### חיבור ה־KV בפריסה הראשונה

ב־`wrangler.jsonc` מוגדר binding בשם `STUDIO_KV` עם המזהה של ה־namespace `rebecca-photo-studio-settings` בחשבון ה־Cloudflare של רבקה. אם מקימים את הפרויקט בחשבון אחר, יוצרים namespace חדש (`npx wrangler kv namespace create STUDIO_KV`) ומחליפים את ה־`id`.

המודל שהיה מוגדר בגרסה המקורית נשמר במשתנה `OPENAI_IMAGE_MODEL`. יש לוודא שהוא זמין בחשבון ה־API שלכם, או להגדיר מזהה מודל תמונות זמין התומך ב־images/edits ובאפשרויות המוגדרות בשרת. לא בוצעה יצירה בתשלום בגרסה העצמאית ללא חיבור המפתח.

הגבלת שתי יצירות במקביל היא לכל מופע Worker בלבד, ואינה מכסה חודשית גלובלית. הגדירו מגבלות שימוש בחשבון ה־API לפי הצורך.

## מבנה

- `shared/` — קוד שהממשק והשרת חולקים:
  - `catalog.ts` — הקטלוג: סגנונות, פלטות, סוגי מוצר ואביזרים. כל פריט הוא `{id, label (עברית), icon (נתיב SVG), prompt (אנגלית)}`. הממשק נבנה ממנו והשרת מאמת מולו כל ערך שמגיע מהלקוח. כדי להוסיף אפשרות עורכים רק את הקובץ הזה.
  - `build-prompt.ts` — `buildPrompt(selection, settings)`: פונקציה טהורה שבונה את הפרומפט. נבדקת ביחידה, בלי קריאה בתשלום.
  - `selection.ts` — הבחירה של רבקה (מוצר, סגנון, פלטה, אביזרים, משטח, רקע, תאורה, מצב נר, גוון זכוכית, עטיפה, זווית, אירוע, בקשה מיוחדת) ואימות שלה. משטח, רקע ותאורה ריקים = ברירת המחדל של הסגנון.
  - `recipes.ts` — ארבעת המתכונים המובנים והפעלת מתכון.
  - `brand-geometry.ts` — המרת אחוזים לפיקסלים, יישור, פיזור, הצמדה וחיתוך. פונקציות טהורות ונבדקות.
  - `brand-layout.ts` — מבנה הפריסה (לוגו, סלוגן, טקסט), ברירות המחדל לכל פורמט ואימות.
  - `settings.ts` — ההגדרות המסתנכרנות ואימותן. גרסאות ישנות משודרגות אוטומטית.
- `src/` — הממשק:
  - `Studio.tsx` מרכיב את `components/`: `Header`, `TabRail`, `OptionPanel/*` (קובץ לכל לשונית), `Stage`, `ActionBar`, `HistoryStrip`.
  - `state.ts` — כל המצב ב־`useReducer`; `useStudio.ts` — הפעולות וההשפעות (טעינה, שמירה, סנכרון, יצירה, הורדה).
  - `brand/` — סצנת המיתוג (`BrandScene.tsx`), הייצוא, גופנים ותמונות; `components/BrandEditor/` — מסך העורך; `api.ts` — קריאות לשרת; `studio-storage.ts` — IndexedDB.
- `worker/` — אימות, יצירת תמונות והגדרות מסונכרנות בצד השרת.
- `public/assets/` — תוכן ותמונות מקוריות.
- `wrangler.jsonc` — תצורת Cloudflare.
- `tests/` — בדיקות (`npm test`, ללא פניות בתשלום): גישה ונתיבי שרת, קטלוג, גיאומטריית המיתוג, בניית הפרומפט ומקטעי המוצר (כולל snapshot של פרומפטים שנבדקו ביד, ב־`tests/fixtures/`), מתכונים, ההיסטוריה, הגדרות ו־KV, והמצב של הממשק.
