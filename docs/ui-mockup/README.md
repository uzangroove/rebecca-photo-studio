# מוקאפ הממשק — מאושר

שלושה מסכים שרבקה אישרה כבסיס לעיצוב החדש:

- `main-screen.dc.html` — המסך הראשי (מחשב / טאבלט): פס לשוניות, אריחים עם אייקונים, תמונה גדולה במרכז, בלי גלילה.
- `brand-editor.dc.html` — עורך המיתוג: ידיות, קווי עזר, סרגל יישור, אזור המוצר, פריסה לכל פורמט.
- `phone.dc.html` — גרסת הטלפון.

הקבצים נוצרו בקנבס העיצוב של Claude ומשמשים כהפניה למבנה, לצבעים, לגופנים ולאייקונים. ראו CLAUDE.md.
